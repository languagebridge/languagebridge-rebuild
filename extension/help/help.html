How to use it, and where to get help

Don't see the toolbar?

LanguageBridge works on school webpages, articles, and Google Docs. Chrome does not let it run on a new empty tab, the Chrome Web Store, or Chrome's own settings and reader pages.

Open the page you are reading for class. If the toolbar still does not show, reload that page.
